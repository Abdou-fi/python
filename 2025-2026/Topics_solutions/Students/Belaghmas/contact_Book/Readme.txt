Project Name: Contact Book GUI
Language: Python
Library Used: tkinter
Description:
This project is a graphical Contact Book using Python's tkinter library.
Users can add, view, and delete contacts using a simple interface.
- Add Contact: Opens a popup to enter name and phone number.
- Delete Contact: Select a contact from the list and delete it.
- All contacts are displayed in a scrollable list within the main window.

How to Run:
1. Open terminal in the project directory.
2. Run the file using:
   python contact_book_gui.py
3. The GUI window will appear, and you can start adding or deleting contacts.
